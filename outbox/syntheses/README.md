## How to use this archive

When citing or being asked about external syntheses of the PCI framework:

1. **Default to the canonical Φ-verified record** in `outbox/paper{4,6,7,9,10}/`. Those are the audited claims.
2. **Use the synthesis PDFs as evidence of how outsiders see the archive** — useful for grant applications, collaboration proposals, and tracking how the framework's external readability evolves over time.
3. **Treat the audit flags above as binding.** Theorem 9.1 vs 9.2, the PCI/PCI homonym, the 13% numerology, and FTW-isn't-yours are the four most common external misreadings.

## Adding a new synthesis

When a new external synthesis lands:
1. Copy the source file (PDF/MD) to `outbox/syntheses/<source>_<topic>_<YYYY-MM-DD>.<ext>`.
2. Add an entry to this README with: scope, what-it-gets-right, what-original-content-is-new, what-it-fuses-or-decorates.
3. If it surfaces a paper-candidate thesis, capture that thesis in `outbox/paper{N+1}/paper{N+1}_thesis_<topic>.md` *while the framing is fresh*, before it decays.
