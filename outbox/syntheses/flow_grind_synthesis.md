# Flow vs Grind, Visits vs Residence: A Cross-Domain Synthesis

**Date:** 2026-05-09
**Status:** Working synthesis. Paper 14 candidate framing.
**Author:** Martin L. Graise, with agent collaboration.

## The one-sentence thesis

The same temporal-pattern-of-occupancy distinction shows up, under
different names, across pharmacology, exercise physiology, phenomenology,
and the framework's own §3.5/§3.6 topology. Convergent vocabulary
across silos suggests the distinction is substrate-independent.

## The four vocabularies for one distinction

| Domain | Flow / healthy regime | Grind / pathological regime |
|---|---|---|
| Framework (Paper 12 v1.4) | §3.5 smooth-interior (4/28 seed cells) | §3.6 boundary-KKT residence (24/28 remainder) |
| Exercise physiology | Endogenous boundary operation: visits to boundary with intact feedback, smooth-interior recovery enforced, flow-shaped adaptations (healthy athlete's heart) | Operator-sustained boundary operation: pharmacological silencing of rate-limiters, sustained boundary residence, boundary-shaped adaptations (arrhythmia phenotype) |
| Pharmacology (Copeland lineage) | Visit-dominated receptor regime: many short binding events, rapid re-association, transient occupancy | Residence-dominated receptor regime: few long-lived binding events, sustained occupancy, durable pharmacology |
| Phenomenology / PCI | Flow: §3.5 occupancy with brief §3.6 touches; Deep rest: §3.5 resident | Rumination / depression / stuck thought loops: §3.6 residence without §3.5 recovery |

The rows describe *different substrates* but *the same structural
distinction*. In each case, the naive framing would say "the pathology
is the boundary region." The mature framing in each domain says:
pathology is the temporal pattern of occupancy, not the occupancy
itself. Residence-where-visits-were-design is the common signature.

## Why this matters

### 1. Convergent vocabulary is strong validation

When pharmacology (Copeland, Vauquelin, Sykes, Bosma) and the framework
arrive at the same visits-vs-residence distinction from completely
different starting points — drug-target binding kinetics versus
tensor-algebraic tear topology — the distinction is probably not a
framework artifact. It is probably a real structural feature of any
dynamical system that has both regimes available to it.

### 2. The pathology grammar is portable

A single grammar appears to cover:
- Drug-induced side effects (chronic receptor residence producing
  off-target durability, e.g. D2 EPS liability)
- Stack-induced cardiac remodeling (operator-sustained boundary
  residence producing arrhythmia phenotype)
- Rumination and depression (phenomenological residence without
  transition machinery)
- Protein misfolding diseases (conformational residence where
  transits were design intent — pending Lane 3 confirmation)
- Gradual tear (Paper 12 substrate-side demonstration)

### 3. The prescription is the same across domains

Pathology in each case is not the system visiting a region. It is the
return-path machinery failing. The therapeutic target is therefore
not "keep the system out of the boundary" but "restore the transition
machinery that returns the system from the boundary." In each domain,
this reframe matches what works clinically:

- Psychedelics restore transitions between locked phenomenological
  states (Carhart-Harris REBUS model)
- Chaperones restore transitions away from misfolded conformations
- Parasympathetic practices (breath, cold exposure, sleep) restore
  transitions away from sympathetic-dominant states
- Drug-holiday / rebinding-limit design in pharmacology restores
  physiological occupancy patterns

## The Copeland anchor case

The Copeland residence-time literature is the most mature expression
of this principle in any domain. Key structural features that the
framework should import:

**The open-system vs closed-system distinction (Tummino & Copeland
2008).** Laboratory equilibrium assays are closed systems. Physiology
is an open system with fluctuating ligand concentration. In open
systems, the decision variable shifts from affinity (a closed-system
snapshot) to residence time (an open-system temporal property). The
framework analog: all of our cross-domain claims are about *open
systems where local temporal structure matters*. Equilibrium / steady-
state framings miss the essential variable.

**The four-point audit design (Copeland Lane 2 report page 9).** For
any residence-vs-visits claim to be rigorous, one must report: (1)
full kinetic quartet (magnitude + temporal constants), (2) pair
biochemical values with washout-sensitive functional assay, (3) in
vivo occupancy after bulk agent clearance, (4) local temporal
modifiers. Without these four, residence-vs-visits attribution fails.
The framework adopts this as a portable audit template for all
cross-domain claims.

**The visit-dominated counterexample is real (β2AR, D2 revised).**
Not every system has both regimes available. Some are intrinsically
visit-dominated (efficacy tracks rapid re-association, not dwell
time). The framework should preserve this: the principle is not
"residence is always pathological" but "regime mismatch is
pathological." Forcing residence in a visit-natured system, or
forcing visits in a residence-natured system, both produce
pathology.

## Paper 14 framing

Originally I considered "residence-where-visits-were-design" as a
unifying contribution. Lane 2 (Copeland pharmacology) showed that
pharmacology already has this explicitly for drug-target systems.
The contribution therefore is not principle invention. It is:

**Cross-domain unification of the visits-vs-residence distinction as
a general pathology grammar, with the framework's §3.5/§3.6 topology
as the substrate-agnostic formal model.**

Paper 14 structure:

1. The Copeland anchor — pharmacology already names this
2. Exercise physiology — endogenous vs operator-sustained boundary
   operation (saturation memo material)
3. Proteostasis — residence in native-adjacent conformations (Lane 3
   material, pending ChatGPT Pro return)
4. Phenomenology — PCI as residence-pattern language for mental states
5. The substrate-agnostic claim — §3.5/§3.6 topology as the formal
   model that underlies all four
6. The return-path-machinery hypothesis — pathology is machinery
   failure, not region identity; therapeutic target is transition
   restoration
7. The four-point cross-domain audit design (Copeland-style,
   adapted)

This is a different paper from what Paper 14 would have been if Lane
2 had returned "nobody has said this." It is more defensible because
it sits on existing literature, and it is more ambitious because
cross-domain unification is a bigger claim than domain-specific
principle invention.

## Open questions

1. **Does proteostasis have the same explicit language?** Lane 3 will
   tell us. If yes: strong convergent-vocabulary case. If no: Paper
   14 imports the vocabulary into proteostasis as one of its moves.

2. **What is the formal version of "regime mismatch"?** Forcing a
   visit-dominated system into residence produces one kind of
   pathology. Forcing a residence-dominated system into visits
   produces another. What is the framework machinery for this?

3. **Is the return-path-machinery class itself classifiable?**
   Chaperones (protein), parasympathetic tone (cardiovascular),
   REM/NREM cycling (brain), allosteric regulators (enzymes),
   rituals and recovery practices (cognition/culture). Are these all
   instances of one mathematical class, or a heterogeneous collection
   that happens to serve the same role?

4. **Can the four-point audit design be generalized?** Copeland's
   version is substrate-specific (receptors). Our version would need
   to generalize: what is the equivalent of "pair biochemical values
   with a washout-sensitive functional assay" for phenomenology? For
   proteostasis? For exercise physiology?

## Non-goals

This is not a medical claim. Nothing in the framework authorizes
specific clinical recommendations. The cardiac / stack example is a
structural observation supported by pharmacology analog; it is not
advice and should never be framed as advice. The audit-window
principle applies here: the framework observes the structure; the
clinical work remains the domain of the clinical literature.
