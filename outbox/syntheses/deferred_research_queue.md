### CC-1: Inter-brain synchrony and dual-EEG literature (from preverbal_research_lanes.md)

**Original prompt target:** Test whether the dual-EEG /
hyperscanning literature (Hasson, Stephens, Dumas, Konvalinka,
Novembre, Pérez) has formalized conversation as a coupled-
dynamical-system phenomenon with two-axis residence observables,
particularly under coupling-breakdown conditions.

**Why it matters:** Paper 14 §8.6 and the negative-pressure memo
propose a dual-EEG experiment where inter-brain beta-phase
coupling increases during a held pause. This prediction is
counterintuitive and load-bearing. The CC-1 lane would test
whether anyone has already done this experiment or a close
cousin.

**Defer to:** Post-Paper-14 v1, before any experimental
collaboration is pursued. Run as an adversarial Deep Research
lane specifically targeting 2020-2026 hyperscanning literature.

**Predicted finding:** Inter-brain synchrony is well-documented
during coordination and cooperation; synchrony during
*coupling-breakdown* (held pauses, mid-sentence stops) is a
specific sub-case probably not yet directly tested. The
experiment is likely novel.

## Methodology observations to capture

### Dual-model Deep Research as methodology

**Observation:** Running the same prompt on both Claude and
ChatGPT Pro in parallel for Lane 3 produced complementary rather
than redundant returns — Claude interpreted "residence" as
temporal, ChatGPT Pro as spatial. The divergence surfaced the
two-axis structure of the framework's observable, which would
have been invisible to a single-model run.

**Why it matters:** This is a methodological finding worth
capturing for future framework work. Dual-model runs are expensive
but surface conceptual structure that single-model framing
collapses.

**Use case:** For any future claim that depends on conceptual
decomposition, run parallel dual-model Deep Research to reveal
the hidden axes.

**Defer to:** Book methodology chapter (if the book has one) or
a short methodology note before Paper 14 submission.

### Adversarial-mode prompting as default

**Observation:** Every lane that was run in adversarial mode
produced sharper, more defensible returns than a charitable-mode
run would have. Lane 5 canalization was the decisive example.

**Why it matters:** Framework-level discipline. Default to
adversarial mode for all future prior-art surveys.

**Use case:** Already being applied. Capture as standing
convention.
