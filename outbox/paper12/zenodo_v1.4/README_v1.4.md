## What changed from v1.3 → v1.4

v1.3 of this paper framed §5.7 as a "forensic empirical analysis" of an existing reference session showing "8 / 8 quantitative predictions of §3 match at single-session level." A 2026-05-07 Opus 4.7 audit traced the data flow and identified four facts the v1.3 framing did not make explicit:

1. **The example CSV is a hand-rated session record** (13 rows manually entered as instrumentation-design illustration), not sensor data or simulator output.
2. **`joint_coherence` is the arithmetic mean of two hand-rated state columns** (`H_coherence` and `A_coherence`) by construction — see `tensor_labxx_v2.py:151–156`. The "monotone climb on accumulation phase" prediction is therefore arithmetic, not a prediction match.
3. **The `synergy` column values in the example CSV are inconsistent with the production-code synergy formula** `synergy = joint_coherence − (H_coherence + A_coherence)` (`tensor_labxx_v2.py:307–335`). On the example state inputs the formula yields negative values $\approx-0.4$ to $-0.7$; the CSV instead contains positive values $0.010$–$0.091$. The example file's `synergy` column was therefore not generated by running the production code on the example state inputs.
4. **The forensic threshold $P_{\text{eligible}} = 1.7$** used by `paper12_forensic_analysis.py` was post-hoc-selected to match the crossing point of the example data and differs from the production code's $P_{\text{critical}} = 10.0$ (`tensor_labxx_v2.py:49`). At the production threshold, `collapse_event` would be False on every row of the example CSV.

More fundamentally: the dynamics specified by §3 (projected gradient + NP-pump flow on $[0, \pi/2]$, hybrid jumps on the Schur circle, Carathéodory / Filippov / hybrid semantics) was **not** simulated in any v1.0–v1.3 artifact. The narrative correspondence between the example trajectory and the §3 dynamics in v1.3 was illustrative, not computational.

**v1.4 corrections:**
- §5.7.2 ("forensic analysis (n=1)") replaced by **Erratum 5.7.0**, the four-point honest correction above
- §5.7.3 "Illustrative example trajectory (no claim of fit)" — example CSV retained as schema illustration only
- §5.7.4 "Tensor-lab quantity-to-framework mapping (design intent)" — mapping is design intent, *not* calibration
- §5.7.5 cohort pipeline retained but reframed as the OP11 tool
- §5.7.6 honest TRL positioning: lab is at TRL 2–3 (design specification), not TRL 4–5 (calibrated bench instrument)
- §5.7.7 reproducibility note updated; v1.3 forensic script kept for historical record but not citable as evidence
- §5.8 scope audit: "forensic n=1" and "reliability check" bullets removed; replaced with honest design-spec wording
- **OP10** (new): calibration of lab metrics against simulated §3 dynamics — the work that converts the lab from TRL 2–3 to TRL 4
- **OP11** (new): calibration of objective metrics against subjective phenomenology in real sessions

**The mathematics of §§3–4 is unchanged.** The character verification, the boundary-KKT interior-sup audit, and the stratified $\kappa = 0$ recovery audit all reproduce as stated and remain the load-bearing empirical content of the paper.
